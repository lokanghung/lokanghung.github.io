## Brand & Style

This design system embodies a modern, high-precision AI software studio. It projects clarity, intelligence, and engineered refinement. The visual atmosphere is clinical yet energetic—eschewing dark, dystopian tropes in favor of an airy, high-craft, luminous environment that signals clarity of thought, algorithmic transparency, and high execution velocity.

The style fuses **Modern Corporate Realism** with **Engineered Minimalism**:
- Pristine, multi-layered neutral backgrounds that provide immense depth without visual clutter.
- High-contrast slate typography that guarantees effortless legibility across complex prompt interfaces, token inspectors, and model evaluation views.
- Targeted bursts of electric indigo and violet to denote active intelligence, model states, and decisive system actions.
- Fine-line structural boundaries and subtle ambient light that evoke precision instruments and modern developer canvases.

## Colors

The palette establishes an ordered, luminous hierarchy engineered for dense data visualization, terminal interfaces, and canvas workspaces.

### Surface Tones
- **Base Canvas (`#F8FAFC`)**: Cool, desaturated foundation that prevents ocular fatigue caused by pure white screens.
- **Card & Workspace Surface (`#FFFFFF`)**: Pure white elevated modules for primary content nodes, code editors, and floating panels.
- **Sunken & Well Fill (`#F1F5F9`)**: Soft slate-tinted backing for sidebars, data-table headers, terminal wells, and inactive panel segments.

### Text & Contrast
- **Primary Ink (`#0F172A`)**: Deep slate-navy for primary headlines, active values, and critical user inputs.
- **Secondary Body (`#334155`)**: Balanced mid-slate for descriptive copy, metadata titles, and prose.
- **Muted & Labels (`#64748B`)**: Restrained slate for placeholders, table column labels, shortcuts, and de-emphasized metadata.

### Accent & Semantics
- **Primary Accent (`#4F46E5`)**: Electric indigo applied to primary actions, interactive focus states, and foundational highlights.
- **Secondary Accent (`#6366F1`)**: Vibrant violet-indigo used for interactive hovers, agent processing states, and gradient accents.
- **Tertiary Accent (`#3B82F6`)**: Bright electric blue for hyper-specific signals such as prompt tokens, streaming pulses, and informational badges.
- **Border Trim (`#E2E8F0`)**: Low-chroma, razor-sharp perimeter definition that frames components cleanly without heavy visual weight.

## Typography

The type system balances technical rigor with high visual polish:
- **Headlines & Body (`Geist`)**: Used for all editorial copy, interface titles, and operational narratives. Tight negative letter-spacing on display headlines creates a dense, premium hardware aesthetic, while body styles maintain standard breathing room for continuous reading.
- **Technical & Utility (`JetBrains Mono`)**: Used for code blocks, prompt tokens, metrics, terminal outputs, system status pills, and keyboard accelerators. Monospaced elements bring immediate structural clarity to technical dashboards and prompt engineering modules.

## Layout & Spacing

The layout is built on a 12-column adaptive fluid grid with a strict 4px base spatial unit, scaling up to handle full-bleed enterprise desktop screens (up to 1600px max canvas width for analytical views).

### Breakpoints & Spatial Adaptations
- **Mobile (< 768px)**: 4 columns, single-tier stacked cards, pinned bottom utility drawers, `margin` of 1rem, and `gutter` of 1rem. Sidebars collapse entirely into modal drawers.
- **Tablet (768px – 1024px)**: 8 columns, 2-tier flexible columns, static header with collapsible utility sidebar, `margin-tablet` of 2rem, and `gutter` of 1.25rem.
- **Desktop (> 1024px)**: 12 columns, multi-pane workbench layout (fixed 260px primary navigation, fluid workspace canvas, collapsible 360px inspector/parameter bar), `margin-desktop` of 3rem, and `gutter-desktop` of 1.5rem.

Internal component composition relies strictly on the `space-*` scale:
- `space-xs` (4px) and `space-sm` (8px) govern tight inline items, icon-to-label gaps, and chip padding.
- `space-md` (16px) defines standard card interior padding and form field stack spacing.
- `space-lg` (24px) and `space-xl` (40px) segment distinct analytical blocks and model configuration modules.

## Elevation & Depth

Visual depth is achieved through structural layering, luminous backdrops, and diffuse ambient shadows rather than harsh drop-shadows.

### Structural Depth Architecture
- **Layer 0 (Canvas Base)**: `#F8FAFC` flat surface. The foundational desktop upon which all containers sit.
- **Layer 1 (Recessed Well)**: `#F1F5F9` with a subtle inner border (`1px solid #E2E8F0`). Used for code runner consoles, readouts, and inactive pane wells.
- **Layer 2 (Default Container)**: `#FFFFFF` surface with `1px solid #E2E8F0` border and an ambient micro-shadow: `0 1px 3px 0 rgba(15, 23, 42, 0.03), 0 1px 2px -1px rgba(15, 23, 42, 0.02)`.
- **Layer 3 (Floating Overlays / Cards on Hover)**: `#FFFFFF` surface accompanied by a diffused drop: `0 10px 25px -5px rgba(15, 23, 42, 0.05), 0 8px 10px -6px rgba(15, 23, 42, 0.03)`. The border shifts dynamically to `#CBD5E1`.
- **Layer 4 (Modals & Command Palettes)**: High-altitude surface with dual shadows: `0 25px 50px -12px rgba(15, 23, 42, 0.12)` complemented by a soft edge ring (`0 0 0 1px rgba(15, 23, 42, 0.06)`). Overlays utilize backdrop blur (`backdrop-filter: blur(8px)`) over an alpha mask (`rgba(15, 23, 42, 0.25)`).

## Shapes

The geometric framework utilizes moderate, consistent corner curves that balance software utility with approachable modern industrial design:
- Base inputs, buttons, chips, and small panels adopt **0.5rem (8px)** corner radiuses.
- Medium structural containers, cards, and modal dialogs inherit **1rem (16px)** (`rounded-lg`).
- Outer workspace frames and multi-component composite viewports scale up to **1.5rem (24px)** (`rounded-xl`).
- Status indicators, execution tags, and pill badges adopt full rounded caps (`9999px`).

## Components

### Buttons
- **Primary**: Solid `#4F46E5` background, `#FFFFFF` text, `0.5rem` border radius. Subtle hover transition to `#6366F1` with an indigo ambient glow (`0 4px 14px 0 rgba(79, 70, 229, 0.35)`). Active state applies a slight scale down (`scale(0.98)`).
- **Secondary / Outline**: `#FFFFFF` background, `#0F172A` text, `1px solid #E2E8F0`. Hover triggers `#F8FAFC` fill and `#CBD5E1` border tint.
- **Ghost**: Transparent background, `#334155` text. Hover shifts to `#F1F5F9` background and `#0F172A` text.
- **Action Icons**: Height/width locked at 36px/40px with centralized vector icons, maintaining 8px corner radii and ghost/secondary behaviors.

### Input Fields & Textareas
- **Surface**: `#FFFFFF` background with `1px solid #E2E8F0` border, `0.5rem` radius, and 12px 16px internal padding.
- **States**: Hover warms border to `#CBD5E1`. Focus transitions border to `#4F46E5` accompanied by an electric ring: `0 0 0 3px rgba(99, 102, 241, 0.15)`.
- **Labels**: Positioned outside above inputs in `Geist` medium (0.875rem, `#334155`), with secondary constraints or micro-copy rendered in `JetBrains Mono` label styles.

### Chips & Badges
- **Model Tag**: Monospaced font (`JetBrains Mono`), `#F1F5F9` background, `#334155` text, and `1px solid #E2E8F0` outline.
- **Status Pills (Live / Active)**: `9999px` full pill radius. Green/Emerald (`#10B981`) or Indigo (`#6366F1`) subtle tint fill (`rgba(X, Y, Z, 0.08)`) with matching solid text and an animated micro-dot pulse indicator.

### Lists & Data Tables
- **Rows**: Explicit `1px solid #E2E8F0` horizontal divider lines. Transparent background transitioning smoothly to `#F8FAFC` on hover.
- **Headers**: `#F8FAFC` background fill, `label-md` monospaced uppercase typography (`#64748B`), with bottom border accent.
- **Dense Data Cells**: Numerical and identifier columns set in `code-md` for tabular numeric alignment.

### Cards
- Constructed with `#FFFFFF` background, `1px solid #E2E8F0` perimeter border, `1rem` corner rounding, and `space-md` or `space-lg` interior padding.
- Content headers clearly partitioned from bodies using structural flex arrangements; interactive cards elevate with Layer 3 shadows on hover.

### Specialized AI Studio Components
- **Prompt Token Inspector**: Inline syntax highlight chips utilizing soft indigo (`rgba(79, 70, 229, 0.08)`), sky (`rgba(56, 189, 248, 0.1)`), and slate backgrounds, pairing exact token character counts in monospaced sub-text.
- **Streaming Response Bubble**: Framed white canvas with an animated, shimmering electric indigo left-border indicator signifying active LLM response generation.
- **Model Parameter Slider**: Minimal 4px `#E2E8F0` track, filled active track in `#4F46E5`, and a 16px circular white handle with a crisp drop shadow and indigo focus halo.
